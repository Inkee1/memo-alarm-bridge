# MemoAlarm Bridge

**내 메모를 내 기기에 저장하고, PC가 꺼져 있어도 Android가 미리 준비한 음성으로 알려줍니다.**

[English](README.md) · [설치와 복구](docs/installation.ko.md) · [연결 계약](docs/protocol.md) · [검증 상태](docs/verification.md)

Windows 또는 Android에서 메모와 일정을 만들고 필요할 때 자신의 기기를 연결하세요. Android가 발화 파일을 미리 합성하고 OS에 알람을 등록합니다. 폰이 미래 예약을 확인한 뒤에는 해당 시각에 PC·네트워크·AI가 온라인일 필요가 없습니다.

현재는 **개발 미리보기**입니다. Android APK 빌드와 JVM 테스트는 통과했으나 실제 폰의 음성·재부팅·DND·OEM 동작과 화면 조작은 미검증입니다. Windows 패키지 검사는 통과했지만 최신 실행 테스트 일부는 개발 PC의 Application Control 정책에 차단됐습니다. [실측 검증 보고서](docs/verification.md)를 먼저 확인하세요.

## 주요 기능

- PC와 Android 각각 독립 사용: 텍스트·음성 메모, 한 번·매일·선택 요일 일정.
- 알람 전에 오프라인 음성 준비, 발생 건별 정지와 5분 미루기.
- 일회용 초대와 인증서 지문을 확인하는 선택적 기기 연결.
- 양쪽 수정이 충돌하면 두 버전을 보존하고 직접 선택.
- PC 동기화 상태와 폰 예약 상태를 구분. 저장만으로 ‘알람 준비됨’이라고 표시하지 않음.
- 로컬 작업에서 JSON CLI 사용, 선택적으로 저장한 ChatGPT 대화 링크 열기.

중앙 계정·유료 서버·Firebase·별도 AI API 키는 필요하지 않습니다. 음성 메모는 녹음 파일이며 자동 받아쓰기는 제공하지 않습니다. 자동 음성 통화나 자동 녹음도 없습니다.

## 가장 먼저 할 일

1. 체크섬을 확인한 Windows ZIP을 풀고 실행 파일을 여세요. 사용자 영역 설치와 경로를 검토합니다. 자동 시작과 폰 연결은 선택 사항입니다.
2. Android **개발용 APK**의 출처와 서명 상태를 확인한 뒤 직접 설치하세요. unsigned release APK는 별도 서명 없이는 설치할 수 없습니다.
3. 폰에서 설치된 오프라인 TTS 음성을 선택하고 정확한 알람·알림 권한을 허용하세요. 먼저 **1분 뒤 테스트**와 정지를 확인합니다.
4. 동기화하려면 PC에서 접근 가능한 주소의 연결을 켜고, 지문을 대조한 뒤 10분 초대 문자열 전체를 Android에 붙여넣으세요.
5. **지금 동기화** 후 각 폰 상태를 확인하고 PC 종료·폰 오프라인 상태에서도 시험하세요. PC 저장 완료만으로는 폰 예약이 보장되지 않습니다.

[초보자 설치·업데이트·복구 안내](docs/installation.ko.md)에는 직접 승인해야 하는 단계와 실패했을 때 보존할 파일이 정리되어 있습니다. 보안 정책을 끄거나 다른 앱의 서명키를 가져오지 마세요.

## 알아둘 범위

배포 대상은 Windows 10/11 x64와 Android API 31 이상입니다. 활성 규칙 최대 50개, 규칙별 다음 발생 2개를 준비합니다. 반복은 고정 IANA 시간대를 따릅니다. 재부팅 후 첫 잠금 해제 전에는 저장해 둔 유한한 다음 예약만 기본음으로 실행하며, 잠금을 해제해야 개인 음성과 다음 반복 준비를 복원합니다.

알람 음량·Android DND 정책과 선택적 무음 모드 존중 설정이 적용됩니다. 앱은 이 설정을 강제로 바꾸지 않습니다. 강제 종료·권한 철회·오프라인 음성 부재·OEM 제약은 알람에 영향을 줄 수 있습니다. 오프라인 폰은 취소를 받기 전까지 울릴 수 있습니다.

dot에 저장소 URL을 주는 것만으로 cloud dot과 local MCP가 연결되지는 않습니다. 구현한 경로는 **로컬 JSON CLI**이며 계정별 MCP·터널 연결은 별도 검증이 필요합니다. [dot 연동 안내](docs/dot-integration.md) · [지원 범위](docs/support.md) · [보안](docs/security.md).
