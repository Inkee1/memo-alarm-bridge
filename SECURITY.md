# Security reporting

Please do not post notes, recordings, invitations, bearer tokens, bootstrap URLs, databases, signing keys or detailed exploit payloads in public issues.

For a vulnerability, use **Report a vulnerability** in the repository's Security tab if private reporting is enabled. If it is unavailable, open a minimal issue requesting a private contact route without including exploit details or private data. This preview has no guaranteed response time or security support window.

Include the version/commit, affected platform, impact and a reproducible description with synthetic data through the private route. Preserve the original installation/data while investigating. The [security model](docs/security.md) and [verification limits](docs/verification.md) describe current boundaries. No production-ready security assurance is claimed.
