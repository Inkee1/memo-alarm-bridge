# 설치·업데이트·복구

[English](installation.md). 개발 미리보기의 [검증 상태](verification.md)를 먼저 확인하세요.

## Windows

신뢰할 수 있는 배포처에서 전체 x64 ZIP을 받고 `Get-FileHash -Algorithm SHA256 <zip>` 결과를 배포처 체크섬과 비교합니다. 체크섬은 바뀐 파일을 찾을 수 있지만 배포자 신원을 증명하지 않습니다. 현재 실행 파일에는 코드 서명이 없습니다. SmartScreen 또는 조직의 Application Control이 차단하면 보안 기능을 끄지 말고 관리자 승인 배포본이나 적절히 서명된 빌드를 사용하세요.

ZIP을 모두 풀고 `memo-alarm-bridge.exe`를 여세요. 브라우저가 열리지 않으면 콘솔에 출력된 `http://127.0.0.1:<port>/#bootstrap=...` 링크 전체를 붙여넣습니다. 이 링크는 다른 사람에게 보내지 마세요. 세션을 승인한 뒤 아래 내용을 검토합니다.

| 항목 | 기본값과 효과 |
|---|---|
| 설치 폴더 | `%LOCALAPPDATA%\Programs\MemoAlarmBridge` |
| 개인 데이터 | `%APPDATA%\MemoAlarmBridge\data`, 실행 파일과 분리 |
| 설치 없이 실행 | 데이터 폴더를 사용해 실행, 자동 시작 항목은 만들지 않음 |
| 설치 / 업데이트 | 해시 확인·DB 사본 검증 후 현재 버전 포인터 전환 |
| 로그인 시 자동 시작 | 새 설치는 꺼짐, 기존 설정은 화면에서 검토 |
| 폰 연결 | 새 연결은 꺼짐, 앱에서 따로 켜기 |

설치 후 설치 폴더의 `MemoAlarmBridge.exe`를 사용합니다. 관리 화면에도 별도 세션 승인이 있습니다. 이미 실행 중이면 새 로컬 링크를 받을 수 있습니다. PC 편집·동기화에는 Bridge 실행이 필요하지만, 폰이 준비하고 등록한 알람은 PC와 독립 동작합니다. 설치가 끝나면 설치 콘솔을 닫으세요. 브라우저 탭만 닫으면 설치 프로세스는 남습니다.

## Android는 단독 테스트부터

`android-debug.apk`는 프로젝트 안에서 만든 폐기 가능한 개발 키로 서명됩니다. 빌드 폴더를 지우면 키가 바뀔 수 있어 안정적인 업데이트 채널이 아닙니다. `android-unsigned.apk`는 별도 서명 없이는 설치할 수 없습니다. 운영 서명키 생성·보관은 사용자가 따로 결정합니다. [빌드·서명 안내](building.md).

APK를 폰으로 옮긴 뒤 설치를 직접 승인하세요. Android가 설치 출처 허용을 요구하면 해당 출처를 확인하고, 필요하면 설치 후 임시 허용을 철회합니다. 조직 정책이 설치를 금지하면 우회하지 마세요. 프로젝트가 자동으로 폰에 설치하지 않습니다.

설정에서 **정확한 알람**, **알림**을 허용하고 **설치된 오프라인 TTS 음성**을 선택합니다. 음성이 없으면 시스템 TTS 설정에서 원하는 음성을 직접 설치한 뒤 돌아와 재확인하세요. 마이크 권한은 녹음 버튼을 눌렀을 때만 필요하며 텍스트 메모·알람에는 필요하지 않습니다.

먼저 **1분 뒤 테스트**로 폰 상태, 실제 소리, 정지, 5분 미루기를 확인하세요. 본인이 정한 알람 음량과 DND 정책을 사용합니다. 앱은 음량·DND를 강제로 바꾸거나 전체 화면 권한을 요구하지 않습니다.

## 선택적 기기 연결

1. 폰이 PC의 선택 주소에 도달할 수 있어야 합니다. 같은 Wi-Fi여도 격리·방화벽 정책 때문에 막힐 수 있습니다. VPN은 선택이며 직접 설정합니다.
2. PC 연결 화면에서 주소·포트를 검토하고 **폰 연결 켜기**를 승인합니다. 보호된 TLS 키를 만들고 재시작 시 연결을 복원할 설정을 저장합니다. 방화벽·공유기·VPN은 변경하지 않습니다.
3. Windows가 네트워크 접근을 물으면 프로그램과 네트워크 범위를 직접 확인하세요. 필요한 사설 네트워크만 허용하고 관리 화면을 인터넷에 노출하지 마세요.
4. 10분 초대를 만들고 문자열 **전체**를 Android 설정에 붙여넣습니다. 주소와 전체 인증서 지문을 PC와 대조한 뒤 페어링을 승인하세요. 보호된 기기 인증자료가 만들어지고 백그라운드 동기화가 켜집니다.
5. **지금 동기화** 후 대기·충돌·각 폰 예약 상태를 확인합니다. 백그라운드 동기화는 연결 시 약 15분 간격의 최선 노력 작업으로 지연될 수 있습니다. 알람 실행 시계를 대신하지 않습니다.

연결한 모든 기기는 같은 컬렉션을 읽고 수정할 수 있습니다. 접근 해제·연결 제거는 폰의 기존 알람을 취소하지 않습니다. 필요하면 폰에서 직접 취소하세요. 오프라인 폰은 취소 수신 전까지 울릴 수 있습니다.

## 막혔을 때

| 증상 | 복구 방법 |
|---|---|
| 실행 파일 차단 | 보안 정책 유지. 승인된 배포본 또는 서명된 빌드 사용. 개발 환경에서도 실제 차단이 발생했습니다. |
| 로컬 승인 링크 실패 | 같은 브라우저를 사용하거나 설치한 앱을 다시 열어 새 링크를 받으세요. 링크를 공개 이슈에 붙이지 마세요. |
| CLI `not_running` | 같은 `--data` 폴더로 Bridge를 시작하세요. |
| 업데이트 중 실행 중 오류 | 새 ZIP의 설치 화면에서 Bridge 종료 후 잠시 기다려 다시 누르세요. 폰 알람은 유지됩니다. |
| 체크섬 불일치 | 데이터·기존 버전 보존. 새로 다운로드해 전체 압축 해제 후 재확인하세요. |
| 공간 부족 / DB 검증 실패 | 새 파일·임시 DB 사본·백업 공간 확보 후 호환 버전으로 재시도하세요. 원본 DB와 기존 포인터를 유지합니다. |
| 실행 파일 / current.json 손상 | 확인한 새 설치 프로그램에서 **데이터 보존 제거** 후 다시 설치하세요. 데이터 폴더를 지우지 마세요. |
| DB가 더 새롭거나 손상됨 | 원본과 백업 보관. 호환 앱 또는 정상 DB 스냅샷으로 복구하며 빈 DB로 덮어쓰지 마세요. |
| 초대 만료 / 시간 차이 | 기기 시계를 확인하고 새 초대를 만드세요. 새 초대는 이전 초대를 대체합니다. |
| 폰 연결 실패 | PC 주소·깨어 있는 상태·Wi-Fi 격리·사설 방화벽 정책을 확인하세요. 네트워크 변경은 따로 승인합니다. |
| 지문 / PC 주소 변경 | 예상하지 못한 지문은 수락하지 마세요. [보안 안내](security.md)의 명시적 키 복구와 재페어링 절차를 따르세요. |
| `blocked_permission` | 정확한 알람·알림 권한을 검토하고 앱으로 돌아와 재확인하세요. |
| `blocked_audio` | 설치된 오프라인 음성·여유 공간을 확인하세요. 이전 버전의 예약이 유지될 수 있으며 별도 표시합니다. |
| 충돌 | 설정에서 두 버전을 비교하고 직접 선택하세요. 취소된 알람을 다시 켜면 새 epoch를 만듭니다. |
| APK 서명 불일치 | 자동 제거하지 마세요. 같은 키로 서명한 업데이트를 받거나 중요한 자료를 보존한 뒤 재설치를 직접 결정하세요. |

## 백업·업데이트·제거

PC 내보내기는 메모·일정·폰 보고의 JSON이며 음성 blob·보호된 키·모든 연결 설정을 담지 않습니다. 전체 백업은 **Bridge 종료 후** 개인 데이터 폴더 전체를 복사하세요. `blobs`와 SQLite 파일을 함께 보관하고 공개 이슈에 올리지 마세요. DPAPI 키는 Windows 계정·PC에 묶여 다른 PC에서는 사용할 수 없을 수 있습니다.

업데이트는 확인한 새 ZIP으로 수동 진행합니다. DB는 `data/backups`에 스냅샷을 남기고 새 프로그램이 사본에서 호환성을 검사한 후 전환합니다. 실제 스키마 변경 전에도 백업을 만듭니다. 이전 실행 파일은 남습니다. 더 새 DB에 오래된 앱을 억지로 실행하지 말고 호환 스냅샷을 사용하세요. 옛 버전·스테이징·백업 파일의 정리는 수동입니다.

Windows 제거는 알려진 앱 파일과 이 앱의 자동 시작 항목만 삭제하고 개인 데이터·알 수 없는 파일은 보존합니다. 폰 알람은 남습니다. 개인 자료 삭제는 필요한 백업 후 별도로 결정하세요.

Android 앱은 클라우드 백업·기기 전송에서 제외되어 있으며 별도 백업/복원 UI가 아직 없습니다. Android에서 앱을 제거하면 폰의 메모·녹음·일정도 지워집니다. 제거 전 필요한 내용을 PC로 동기화하거나 별도로 보관하세요.
